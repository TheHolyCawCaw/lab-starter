# Mon projet

Ce projet est en ligne sur le serveur de la classe :
`https://<nom de ton app>.lab.herbiserver.eu/` (le nom est dans `.lab-app`).
Chaque fois que Claude pousse sur la branche `main`, le site est mis à jour
automatiquement.

## Travailler avec Claude

Écris à Claude ce que tu veux, en phrases normales. Exemples :

- « Fais-moi une page de présentation de mon projet, avec un titre, trois
  sections et une photo. Push sur main et vérifie le déploiement. »
- « Ajoute un formulaire de contact. »
- « Le site affiche une erreur, regarde le dernier déploiement et corrige. »
- « Explique-moi ce que fait ce fichier, ligne par ligne. »

Bons réflexes :

- Une demande à la fois, puis regarde le résultat sur ton site.
- Demande à Claude d'expliquer ce qu'il a fait : c'est ton projet, tu dois
  pouvoir le présenter.
- Si quelque chose casse, dis-le à Claude avec le message d'erreur.

## Où voir quoi

- **Ton site** : l'adresse ci-dessus.
- **Les déploiements** : l'onglet **Actions** de ce dépôt. Vert = en ligne,
  rouge = erreur (clique dessus pour lire le journal, ou demande à Claude).
- **Le code** : l'onglet **Code** de ce dépôt.

## Ce que le serveur sait faire tourner

Un site simple (HTML, CSS, JavaScript), ou une application Node.js, Python ou
PHP. Claude connaît les détails : ils sont dans `CLAUDE.md`.

Besoin d'une base de données ou d'une clé secrète (clé d'API) ? Demande au
prof.

## Règles

- Ton site est public : tout le monde peut le voir.
- Pas de données personnelles d'autres personnes, rien que tu ne montrerais
  pas en classe.
- Jamais de mot de passe ni de clé dans le code.
