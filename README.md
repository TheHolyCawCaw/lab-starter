# Mon projet

Ce projet est en ligne sur le serveur de la classe. Chaque fois que Claude
pousse sur la branche `main`, le site est mis à jour à l'adresse
`https://<nom de ton app>.lab.herbiserver.eu/`.

- Mise en route : la fiche du prof (nom de l'app dans `.lab-app`, secret
  `DOKKU_SSH_KEY` dans les réglages GitHub du dépôt).
- Le déploiement se voit dans l'onglet **Actions** du dépôt.
- Les règles pour Claude sont dans `CLAUDE.md`.
